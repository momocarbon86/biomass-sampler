Overview

Biomass Field Sampler records forest inventory plots and calculates above- and below-ground biomass, carbon and CO₂ equivalent for every stem. It also gives per-hectare values for each plot, averages by stratum and site, and a stratified project estimate. It is a progressive web app: one HTML file that installs on a phone or computer and works offline.

There are two apps. The full app is for project teams: plot register, four record sections, dashboard, quality checks, model selection, exports and backup. Biomass Sampler Lite is a step-by-step version for field helpers and community members. It uses the same calculation engine with the defaults fixed.

Plot design

Each sampling point is a set of nested circular plots sharing one centre. Each section is measured only inside its own circle, and its results are divided by that circle's area.

Custom radii. Every plot stores its own four radii. New plots start from the defaults in settings, or in Lite from the last sizes used. The stump radius follows the tree radius unless you change it.

Recording data

  1. Plot: site and district (add your own), plot number and ID, stratum (dropdown with + Add new stratum…), date, crew, centre coordinate, radii and, optionally, a plot-specific model.
  2. Records: in each section, search a tree by local, English or scientific name. The scientific name, species code and wood density fill in automatically. Enter the tape reading as circumference or diameter, and the height where needed.
  3. Check: the dashboard and Results update immediately, and the data quality checks list anything to fix.
  4. Export and back up: see Exports and Sharing and backup.

Every record can be edited or deleted, with Undo. Records always belong to the plot that was active when they were entered.

Diameter

When a circumference (girth) is entered, DBH is calculated as:

D (cm) = C (cm) ÷ π

Above-ground biomass (AGB)

Missing height. If a model needs height and a stem has none, that stem uses a diameter-only model: Chave 2005 dry forest (no height) for the Chave models, and Mugasha 2013 for the others. The stem is flagged in the data quality checks and in the exports.

Outside the range. Stems with DBH outside the range used to fit a model are still calculated, but flagged.

Ryan (2011) gives carbon, so the app divides by 0.47 to convert it to biomass.

Carbon standards such as Verra's VMD0001 require each project to justify its allometric equation for its forest type. Check your methodology before choosing a model.

Wood density

Each stem uses the first of these that is available:

  1. a value typed on the record;
  2. the species mean from the Global Wood Density Database v2;
  3. the genus mean from the same database;
  4. the default of 0.619 g/cm³ (Chidumayo 2012), which can be changed in settings.

The source used is saved with the record and exported. Wood density only affects models that use ρ.

Carbon and CO₂e

AGC = AGB × CF    BGC = BGB × CF    Total C = AGC + BGC
t CO₂e = t C × 44/12

CF is the carbon fraction: 0.47 by default (IPCC 2006). It can be changed in settings; for example, Zambia's FREL uses 0.49. 44/12 is the ratio of the molecular weight of CO₂ to the atomic weight of carbon. All carbon is reported in tonnes.

Dead wood (stumps)

Volume (m³) = π × (D/200)² × H    Biomass (kg) = Volume × ρdw    C (kg) = Biomass × CF

D is the stump diameter in cm and H its height in m. ρdw is the dead-wood density, 619 kg/m³ by default and editable in settings. A legacy formula switch in settings reproduces an older spreadsheet method for comparison.

Per-hectare values

Each section is divided by its own circle area:

A (m²) = π × r²    t C/ha = (Σ kg C ÷ A) × 10
Plot t C/ha = saplings + trees + dead wood    Regeneration stems/ha = N ÷ A × 10,000

Averages and confidence

For n plots in a group (stratum, site or all plots), with plot values x:

mean = Σx ÷ n    SD = √(Σ(x − mean)² ÷ (n − 1))    SE = SD ÷ √n
95% CI = mean ± t0.05, n−1 × SE

The t value comes from Student's t distribution, so small samples get wider intervals.

Project estimate

Enter the area (ha) of each stratum on the dashboard. The stratified estimate is:

Total (t C) = Σ Ah × meanh    SEtotal = √Σ (Ah² × SEh²)
90% CI = t0.10, df × SEtotal    df = smallest n − 1 among strata with an area

The app also gives the total in t CO₂e, the CI as a percentage, and the lower 90% bound. This estimate is indicative; check it against your methodology's uncertainty rules.

Data quality checks

  • plots without a coordinate, or with GPS accuracy worse than the setting;
  • plots with no records;
  • saplings or trees in the wrong DBH class;
  • heights outside 1.3–45 m, and DBH over 150 cm;
  • stems where a fallback model was used, or outside the model's DBH range;
  • records with no scientific name.

Tap a check to open the plot or record.

Exports

All coordinates are WGS84 (EPSG:4326) decimal degrees, to 6 decimal places.

  • Excel workbook with formulas (.xlsx): see below.
  • CSV: plot summary, regeneration, saplings, trees and stumps, separately or together as a ZIP. Stem files include wood density and its source, the models used, and fallback and range flags.
  • KML: plot centres and nested ring polygons, for Google Earth or QGIS, with GPS accuracy.
  • GPX: plot-centre waypoints for handheld GPS units.
  • JSON backup: everything, to restore or merge on another device. Cloud passwords are never included.

Lite app

Lite walks through one plot at a time: Plot → Young plants → Small trees → Big trees → Stumps → Result. It uses the default method (Chidumayo 2012, R:S 0.28, CF 0.47, 619 kg/m³) and lets the user set the plot radii. Measurements are entered with a tape around the trunk, or with a diameter tape. The app warns when a stem belongs in another size class.

Lite exports one Excel workbook (sheets: Plot summary, Young plants, Small trees, Big trees, Stumps, About), a single CSV table with a Record type column, and a data file. The data file is opened in the full app with Export & settings → Restore / merge backup.

Sharing and backup

  • Share data (full app) and Share Excel file (Lite) open the phone's share list: WhatsApp, email, Bluetooth, Google Drive, OneDrive, Teams and so on.
  • Android Chrome only lets web apps share some file types (CSV and text, but not Excel). On Android, an Excel file is saved first and then sent from the Files app, or the data is shared as CSV. iPhones share Excel files directly.
  • Automatic cloud backup (full app): connect Google Drive (through a small Google Apps Script in your own account) or OneDrive (Microsoft sign-in). After changes, a JSON backup and CSV files are uploaded to your own storage.

GPS accuracy

The app only accepts fixes at or better than the required accuracy: ±4 m by default, adjustable from 0.1 to 4 m. Up to 20 accepted fixes are averaged, weighted by 1/accuracy², and the plot stores the achieved accuracy and number of fixes. If the limit isn't reached, Use best fix so far appears, and plots saved that way are flagged. Sub-metre accuracy needs an external GNSS receiver; on Android, set it as the mock location provider.

Troubleshooting: location only works over https or in the installed app. If permission is blocked, allow Location for the browser or app in the phone settings. Under heavy canopy, wait in a clearing, or paste coordinates. Decimal degrees, degrees-minutes-seconds and Google Maps links are all accepted.

Species list

The app has 2,561 names for 702 tree species. Local names are in Bemba, Nyanja, Tonga, Lozi, Kaonde, Lunda, Kunda, Senga and Tumbuka, alongside English and scientific names. Where one local name is used for several species, all of them are shown. The scientific name fills in automatically only when the match is certain. Wood density is matched for 653 species: 393 at species level and 260 at genus level.

Settings

  • default allometric model, root model and custom coefficients a and b;
  • carbon fraction, root-to-shoot ratio, default wood density and dead-wood density;
  • default plot radii, and the DBH thresholds for saplings and trees;
  • required GPS accuracy;
  • project sites and districts, and strata;
  • cloud backup, data restore and merge, and deleting all data.

Installing the app

  1. Host it: put the app's www folder on any https host, such as Netlify, GitHub Pages or your own server. The Lite app sits in www/lite/.
  2. Install on phones: open the link in Chrome or Safari and choose Add to Home screen. It then works offline.
  3. Google Play: package the hosted app with PWABuilder (Trusted Web Activity) and publish it through the Play Console.
  4. Updates: re-upload the files. Installed apps update the next time they go online.

Data and privacy

All data stays in the browser storage on the device until the user exports, shares or backs it up. Cloud backups go only to the user's own Google Drive or OneDrive. The app collects no personal data, and location is used only to record plot coordinates. Clearing the browser or uninstalling removes local data, so back up first.
