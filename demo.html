Try both apps

These are the real apps, running in your browser with a made-up demo project of 32 plots. In each demo you can add one plot of your own, with as many trees as you like. Anything you add stays only in your browser. Tap Reset on the yellow DEMO badge to go back to the sample data.

Biomass Field Sampler (full app)

Tips for the demo
  • On a phone: use Open full screen for the best view. GPS and sharing work there.
  • Demo limits: the data is made up. You can add one plot of your own, but not import data. The demo does not install as an app or back up to the cloud.
  • Real projects: install the production version on your phones. See Installing the app.
