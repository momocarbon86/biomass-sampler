Automatic cloud backup

After every change, a copy of all data (JSON backup plus the five CSV files) goes to Google Drive and/or OneDrive. It waits 15 seconds after the last edit, and retries when the connection returns.

Cloud backup works in the hosted or installed app, not inside this preview.

Google Drive

  1. Tap Create secret key, then Copy Google script.
  2. Open script.google.com → New project, paste the script, then Deploy → New deployment → Web app, Execute as Me, access Anyone. Approve the Drive permission.
  3. Paste the Web app URL below. Backups appear in the Drive folder “Biomass Field Sampler backups”.

OneDrive

  1. At entra.microsoft.com → App registrations → New registration: any name, accounts in any organisation and personal Microsoft accounts.

Allometric models & default plot sizes

The models chosen here are the defaults for new plots; each plot can use its own. The default, Chidumayo (2012) with the IPCC root ratio, is the model named in Zambia’s FREL. Carbon = biomass × CF. Stump C = volume × dead-wood density × CF.

Project sites & districts

Choosing a site fills in its district on the plot form. You can change a district here. Sites you added can be removed if no plot uses them.

Strata

The strata offered on the plot form. Strata used by a plot can't be removed.

Species list

Built from your species code list, the names in your field sheets, Mr. Garry's Collection of Zambian Trees (Bemba, Nyanja, Tonga, Lozi, Kaonde, Lunda, Kunda, Senga, Tumbuka and English names), the ICRAF Agroforestree database and other Zambian species. You can search by local, English or scientific name. Where one local name is used for more than one tree, all of them are listed, so pick the right species. Names you add here are listed first.
